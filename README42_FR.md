# The Answer Protocol : Une aventure textuelle rétro se déroulant dans un univers partagé

## Description

Avant l’apparition des « loot boxes » et des « battle passes », les aventuriers se connectaient à des mondes partagés entièrement composés de texte. Ces jeux s’appelaient les **MUD** (Multi-User Dungeons) et fonctionnaient sur les réseaux universitaires et les serveurs d’amateurs.

Dans « The Answer Protocol », l'objectif est de créer son propre petit monde, où plusieurs joueurs pourront explorer des pièces, discuter et coopérer en temps réel. Pour cela, il nous est demandé d'utilier un protocole TCP simple, basé sur des lignes de commande, et deux clients: l’un en ligne de commande et l’autre graphique. 

## Instructions

### Les éléments obligatoires

- **Langage** : Go 1.22 ou plus récent
- **Compilateur** : Un compilateur C (GCC, Clang, ...) pour utiliser Fyne

### Les commandes importantes

```bash
make install
make build
make run-server
make run-client
```
